# Ch01_Setup_19_ImportBackgroundAssets_REVIEW

## 리뷰 대상

이번 리뷰 대상은 Starfield 배경 에셋 import 커밋이다.

커밋 요약:

- `Assets/StarfieldMaterials` 폴더 추가
- 배경용 머티리얼, README, 예제 씬, 예제 스크립트 추가
- Plain Starfields, SingleNeb 텍스처 추가
- 기존 게임 씬과 게임 스크립트 수정 없음

## 전체 평가

이번 작업은 게임 배경을 더 우주 슈팅 게임처럼 보이게 만들기 위한 준비 단계로 적절하다.

현재 프로젝트는 Player, Enemy, Bullet, 폭발 이펙트까지 기본 슈팅 구조가 잡혀 있다.  
이제 배경까지 우주 느낌으로 정리하면 게임의 완성도가 더 올라간다.

이번 단계에서 기존 게임 로직을 건드리지 않고 배경 에셋만 import한 점이 좋다.

## 좋은 점

### 1. 기존 게임 로직을 수정하지 않았다

이번 단계에서는 에셋만 추가했고, 기존 게임 씬이나 게임 스크립트를 수정하지 않았다.

에셋 import와 실제 적용 단계를 분리했기 때문에 문제가 생겼을 때 원인을 찾기 쉽다.

### 2. 사용할 수 있는 배경 텍스처가 여러 개 있다

다음 두 계열의 텍스처가 들어왔다.

- Plain Starfields
- SingleNeb

즉, 단순 별 배경과 성운 느낌 배경을 모두 사용할 수 있다.

수업에서는 먼저 가장 단순한 배경 하나를 고르고,
나중에 Overlay나 성운 레이어를 추가하는 방식으로 확장할 수 있다.

### 3. 머티리얼이 함께 들어 있다

머티리얼이 이미 포함되어 있으므로, 텍스처를 바로 씬 오브젝트에 적용하기 쉽다.

예:

```text
Starfield_01_Material.mat
Starfield_Overlay.mat
Nebu_far.mat
```

이 점은 초급 수업에서 배경 적용 단계를 단순하게 만드는 데 도움이 된다.

### 4. 다음 단계로 이어가기 좋다

이제 다음 단계에서 바로 배경을 씬에 적용할 수 있다.

예상 흐름:

```text
SampleScene에 Quad 또는 Plane 배치
→ Starfield 머티리얼 적용
→ 카메라 기준 뒤쪽에 배치
```

또는 더 간단하게는 기존 배경 오브젝트를 하나 만들고 텍스처를 적용할 수도 있다.

## 확인이 필요한 점

### 1. Unity import 오류 확인

Unity Editor에서 Console을 확인해야 한다.

확인할 내용:

- PNG import 오류가 없는지
- 머티리얼 Missing reference가 없는지
- `Move.cs` 컴파일 오류가 없는지

### 2. 예제 씬 확인

`DemoScene.unity`를 열어 보면 배경 에셋이 어떤 방식으로 보이는지 확인할 수 있다.

다만 예제 씬은 참고용이고, 실제 수업 프로젝트 작업 씬은 `SampleScene`이다.

### 3. 기존 게임 씬 유지 확인

이번 커밋에서는 기존 게임 씬을 수정하지 않는 것이 맞다.

따라서 `SampleScene`이 그대로 유지되는지 확인하면 좋다.

### 4. 예제 스크립트 구분

에셋에는 `Move.cs`가 포함되어 있다.

이 스크립트는 배경 스크롤이나 데모 이동용일 수 있지만,
현재 수업용 프로젝트 로직과 직접 연결하지 않는 것이 좋다.

## 개선하면 좋은 점

### 1. 다음 단계에서 사용할 배경 하나를 먼저 고르기

텍스처가 여러 개 있으면 학생들이 선택에 시간을 많이 쓸 수 있다.

강의용으로는 먼저 1개만 기준으로 정해두는 것이 좋다.

예:

```text
기본 배경: PlainStarfield_01
보조 배경: SingleNeb_03
```

### 2. 배경 적용 방식을 단순하게 잡기

다음 단계에서는 너무 복잡한 패럴랙스나 다중 스크롤보다,
먼저 배경 오브젝트 하나에 머티리얼을 붙이는 단순한 방식이 좋다.

이후 필요하면 다음처럼 확장할 수 있다.

- 배경 2겹 구성
- 천천히 아래로 움직이는 스크롤 배경
- 성운 Overlay 추가

### 3. 카메라와 배경 배치 관계 설명하기

현재 프로젝트는 3D 공간 기반 2D 슈팅이다.

따라서 배경을 적용할 때는 다음을 설명하면 좋다.

- 카메라가 보는 방향 기준으로 뒤쪽에 배치
- Player, Enemy, Bullet보다 뒤에 놓이게 배치
- 충돌과는 상관없는 배경 오브젝트로 취급

### 4. 배경 스크립트는 나중에 선택적으로 사용

에셋의 `Move.cs`를 바로 사용하기보다는,
수업 프로젝트 흐름에 맞게 직접 간단한 배경 스크롤 스크립트를 만드는 편이 더 학습에 좋을 수 있다.

## 최종 결론

이번 커밋은 우주 배경 리소스를 프로젝트에 추가하는 단계로 적절하다.

기존 게임 기능을 수정하지 않고 에셋만 import했기 때문에 안전하며,
다음 단계에서 실제 `SampleScene` 배경을 꾸미기 위한 준비가 되었다.
