# Ch01_Setup_05_PlayerFire_REVIEW

## 리뷰 대상

이번 리뷰 대상은 총알 프리팹 생성 및 플레이어 발사 구현 패치다.

패치 요약:

- `Assets/Prefabs` 폴더 추가
- `Assets/Prefabs/Bullet.prefab` 추가
- 씬에 직접 배치되어 있던 Bullet 제거
- `Assets/Scripts/PlayerFire.cs` 추가
- `Player` 오브젝트에 `PlayerFire` 스크립트 연결
- `Player` 자식으로 `FirePosition` 오브젝트 추가
- 발사 버튼 입력으로 Bullet 프리팹 생성

## 전체 평가

이번 작업은 총알 이동 다음 단계로 매우 자연스럽다.

이전 단계에서는 총알이 스스로 움직이는지만 확인했다.  
이번 단계에서는 그 총알을 프리팹으로 만들고, 플레이어가 버튼을 누를 때 생성하도록 바꿨다.

즉, 학생들이 Unity의 중요한 흐름인 다음 과정을 경험할 수 있다.

1. 씬 오브젝트 만들기
2. 스크립트 붙이기
3. 프리팹으로 만들기
4. 스크립트에서 프리팹 생성하기
5. 생성 위치를 별도 오브젝트로 지정하기

## 좋은 점

### 1. Bullet을 프리팹으로 분리했다

총알은 앞으로 여러 번 생성될 오브젝트다.

따라서 씬에 하나 놓는 방식보다 프리팹으로 만들어두는 것이 적절하다.

이번 단계에서 `Assets/Prefabs/Bullet.prefab`을 만든 것은 좋은 구조다.

### 2. 씬에 직접 놓인 Bullet을 제거했다

이전 단계에서는 테스트를 위해 씬에 Bullet을 직접 배치했다.

이번에는 총알이 PlayerFire를 통해 생성되므로, 씬의 루트 Bullet을 제거한 것이 맞다.

### 3. FirePosition을 따로 만들었다

총알 생성 위치를 Player 위치 자체가 아니라 `FirePosition`으로 분리한 점이 좋다.

이렇게 하면 나중에 총구 위치를 조정할 때 코드를 바꾸지 않고 오브젝트 위치만 조정할 수 있다.

### 4. 코드가 수업용으로 단순하다

`Input.GetButtonDown("Fire1")`으로 입력을 받고, `Instantiate`로 총알을 만든 뒤, 위치를 `firePosition`으로 옮기는 구조다.

초급자가 이해하기 좋은 흐름이다.

## 확인이 필요한 점

### 1. 발사 입력 확인

Play 모드에서 발사 버튼을 눌렀을 때 총알이 생성되는지 확인해야 한다.

확인할 내용:

- 마우스 왼쪽 버튼 또는 Ctrl 키 등 `Fire1` 입력이 동작하는지
- 총알이 생성되는지
- 생성된 총알이 위쪽으로 이동하는지

### 2. Inspector 연결 확인

`PlayerFire`는 Inspector 참조가 필요하다.

확인할 내용:

- `bulletFactory`에 `Bullet.prefab`이 연결되어 있는지
- `firePosition`에 `FirePosition` 오브젝트가 연결되어 있는지

이 둘 중 하나라도 비어 있으면 Play 모드에서 오류가 발생할 수 있다.

### 3. FirePosition 위치 확인

현재 `FirePosition`은 Player의 자식이지만 로컬 위치가 `{x: 0, y: 0, z: 0}`이다.

즉, 총알이 플레이어 중심에서 생성된다.

처음 테스트에는 괜찮지만, 화면상으로 자연스럽게 보이려면 Player 위쪽으로 조금 올리는 것이 좋다.

## 개선하면 좋은 점

### 1. 총알 삭제 기능 추가

현재 총알은 계속 생성되고 위로 이동하지만, 화면 밖으로 나가도 사라지지 않는다.

다음 단계에서 총알 삭제 기능을 추가하는 것이 좋다.

가능한 방식:

- 일정 시간이 지나면 삭제
- 특정 y 위치를 넘으면 삭제
- DestroyZone에 닿으면 삭제

초반 수업에서는 일정 시간이 지나면 삭제하는 방식이 가장 단순하다.

### 2. Null 체크 추가

`bulletFactory`나 `firePosition`이 Inspector에서 연결되지 않으면 오류가 날 수 있다.

지금은 수업용 단순 코드로 충분하지만, 나중에 안정성을 높이려면 연결 누락을 확인하는 코드를 넣을 수 있다.

### 3. 발사 위치 조정

`FirePosition`의 로컬 위치를 Player보다 위쪽으로 조정하면 총알이 더 자연스럽게 발사된다.

예:

```text
x: 0
y: 0.7
z: 0
```

### 4. 발사 간격 제한

현재는 버튼을 누를 때마다 총알이 생성된다.

나중에 누르고 있는 동안 계속 발사하거나, 일정 시간마다 발사되게 하려면 별도 발사 간격 처리가 필요하다.
