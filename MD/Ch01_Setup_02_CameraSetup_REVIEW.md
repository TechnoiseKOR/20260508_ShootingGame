# Ch01_Setup_02_CameraSetup_REVIEW

## 리뷰 대상

이번 리뷰 대상은 제작 환경 설정 패치다.

패치 요약:

- `.gitignore`에 `.vsconfig` 추가
- `SampleScene`의 카메라 Orthographic Size를 `3.14`에서 `5`로 변경
- `ProjectSettings.asset`의 `activeInputHandler` 값을 `1`에서 `2`로 변경

## 전체 평가

이번 작업은 실제 게임 기능을 만들기 전 환경 설정 단계로 적절하다.

특히 슈팅 게임에서는 카메라가 보여주는 화면 범위가 중요하다.  
Orthographic Size를 `5`로 조정한 것은 이후 플레이어, 적, 총알을 배치하고 움직임을 확인하기 좋은 준비 작업이다.

## 좋은 점

### 1. 카메라 화면 범위를 넓혔다

기본 Orthographic Size `3.14`는 슈팅 게임 제작 화면으로는 다소 좁게 느껴질 수 있다.

`5`로 변경하면 더 넓은 게임 영역을 볼 수 있어,
이후 오브젝트 배치와 이동 확인이 쉬워진다.

### 2. 실제 게임 기능을 미리 만들지 않았다

이번 단계에서는 플레이어, 총알, 적 같은 기능을 만들지 않았다.

AGENTS.md의 프로젝트 전용 추가 지침처럼,
필요한 기능을 작은 단계로 나누어 진행하는 흐름과 잘 맞는다.

### 3. 로컬 설정 파일 제외가 추가되었다

`.vsconfig`를 `.gitignore`에 추가해서,
개인 개발 환경 설정이 Git에 포함될 가능성을 줄였다.

수업 프로젝트에서는 학생마다 개발 환경이 다를 수 있으므로 적절한 변경이다.

## 확인이 필요한 점

### 1. Game View 화면 확인

카메라 Orthographic Size를 `5`로 바꾼 뒤,
Unity Game View에서 화면 구성이 적절한지 확인해야 한다.

확인할 내용:

- 화면이 너무 넓거나 좁지 않은지
- 플레이어를 배치할 아래쪽 공간이 충분한지
- 적이 등장할 위쪽 공간이 충분한지

### 2. 입력 처리 설정 확인

`activeInputHandler` 값이 변경되었다.

다음 단계에서 플레이어 이동을 구현할 때 입력 관련 오류가 발생하지 않는지 확인해야 한다.

특히 수업에서 Unity 기본 `Input` 방식을 사용할 예정이라면,
첫 입력 코드 작성 단계에서 실제로 키보드 입력이 정상 동작하는지 Play 모드로 확인하는 것이 좋다.

### 3. 씬 저장 상태 확인

`SampleScene.unity`가 수정되었으므로,
Unity Editor에서 씬이 정상적으로 열리는지 확인하는 것이 좋다.

확인할 내용:

- Missing Script가 없는지
- Main Camera 설정이 유지되는지
- Play 모드 진입 시 오류가 없는지

## 위험 요소

큰 위험 요소는 없다.

다만 `ProjectSettings.asset` 변경은 프로젝트 전체 설정에 영향을 줄 수 있으므로,
이후 입력 관련 구현에서 문제가 생기면 이 설정 변경을 먼저 확인하면 된다.
