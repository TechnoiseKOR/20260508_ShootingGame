# Ch01_Setup_01_AGENTS_ProjectGuideline_CHANGE_ANALYSIS

## 분석 대상

이번 문서는 `ShootingGame` 프로젝트에서 생성한 기본 `AGENTS.md`를 기준으로 한다.

기본 `AGENTS.md`는 다음 명령으로 생성한 상태다.

```text
/init AGENTS.md for Unity 6.4 3D 프로젝트 한글로
```

## 현재 AGENTS.md 상태

현재 `AGENTS.md`는 Unity 6.4 계열 3D 프로젝트를 기준으로 생성되어 있다.

주요 내용은 다음과 같다.

| 구분 | 내용 |
|---|---|
| Unity 버전 | `6000.4.5f1` |
| 렌더 파이프라인 | Universal Render Pipeline `17.4.0` |
| 입력 | Unity Input System `1.19.0` |
| 테스트 | Unity Test Framework `1.6.0` |
| 프로젝트 성격 | Unity 6.4 계열 3D 프로젝트 |
| 기본 언어 | 한국어 |

## 이전 AGENTS.md와 달라진 점

이전 `Shooting2D` 프로젝트에서 생성했던 `AGENTS.md`는 이름과 프로젝트 성격 때문에 일반적인 2D 프로젝트 기준으로 해석될 여지가 있었다.

하지만 이번 `ShootingGame` 프로젝트의 `AGENTS.md`는 `/init` 단계에서 3D 프로젝트라고 명시했기 때문에 다음 기준이 더 잘 맞는다.

- Unity 3D 프로젝트 기준
- 3D 물리 사용
- 2D 물리 API와 혼용하지 않음
- URP 기반 3D 프로젝트 관리 기준

특히 기본 문서에 아래 내용이 들어간 점이 좋다.

```text
3D 물리 동작은 Rigidbody, Collider, Physics 설정을 기준으로 구현하고,
2D 물리 API와 혼용하지 않는다.
```

이 내용은 이번 슈팅 게임 프로젝트 방향과 잘 맞는다.

## 추가 지침이 필요한 이유

기본 `AGENTS.md`는 Unity 프로젝트 전체를 위한 일반 작업 기준이다.

하지만 수업에서 진행할 슈팅 게임은 다음과 같은 추가 기준이 필요하다.

- 한 번에 많은 기능을 만들지 않기
- 필요한 파일과 폴더를 미리 만들지 않기
- 기능을 작은 단위로 나눠서 진행하기
- 초보자도 따라갈 수 있는 단순한 코드 작성
- Unity Editor에서 직접 해야 하는 작업을 따로 안내하기

따라서 기본 문서를 고치기보다는,
문서 맨 아래에 `프로젝트 전용 추가 지침`을 추가하는 방식이 적절하다.

## 예상 변경 파일

이번 작업에서 수정되어야 하는 파일은 하나다.

| 파일 | 변경 내용 |
|---|---|
| `AGENTS.md` | 문서 맨 아래에 `프로젝트 전용 추가 지침` 섹션 추가 |

새 폴더나 새 스크립트는 만들지 않는다.

## 추가될 주요 내용

`AGENTS.md` 맨 아래에 다음 항목이 추가된다.

### 1. 프로젝트 방향

- Unity 6.4로 만드는 간단한 슈팅 게임
- 화면은 2D처럼 보이지만 Unity 3D 공간 기준으로 제작
- 작은 기능을 하나씩 추가하면서 완성

### 2. 작업 방식

- 요청한 기능만 구현
- 다음 단계에서 필요할 것 같다는 이유로 미리 만들지 않음
- 필요한 파일과 폴더는 해당 기능 구현 시점에 생성
- 기존 내용을 최대한 유지

### 3. 코드 작성 방향

- 처음 배우는 사람도 따라갈 수 있는 단순한 코드
- 역할을 알 수 있는 변수명과 함수명
- 필요한 경우 짧은 한글 주석 사용
- 고급 구조는 요청 전까지 사용하지 않음

### 4. Unity 작업 안내

- Unity Editor에서 직접 설정해야 할 내용 안내
- 스크립트를 붙일 오브젝트 안내
- Inspector 설정값 안내
- Play 모드 확인 항목 안내

### 5. 보고 방식

- 변경 내용
- 수정한 파일
- 새 파일 또는 새 폴더
- Unity Editor에서 직접 해야 할 일
- 확인하지 못한 내용

## 확인할 점

작업 후에는 다음을 확인하면 된다.

- `AGENTS.md` 외에 다른 파일이 수정되지 않았는지 확인
- 문서 맨 아래에 `프로젝트 전용 추가 지침`이 추가되었는지 확인
- 새 폴더나 새 스크립트가 생성되지 않았는지 확인
- 기존 `/init` 기본 지침이 삭제되지 않았는지 확인

## 결론

이번 단계는 실제 게임 기능 구현 전,
Codex가 앞으로 따라야 할 프로젝트 진행 방식을 추가하는 준비 단계다.

기본 `AGENTS.md`가 이미 3D 프로젝트 기준으로 잘 생성되었기 때문에,
이번에는 기존 내용을 수정하기보다 프로젝트 전용 지침만 아래에 추가하는 방식이 가장 적절하다.
