# Ch01_Setup_01_AGENTS_ProjectGuideline

## 목표

현재 프로젝트 루트에 있는 `AGENTS.md`에 이 슈팅 게임 프로젝트 전용 작업 기준을 추가한다.

이미 `/init AGENTS.md for Unity 6.4 3D 프로젝트 한글로` 명령으로 기본 `AGENTS.md`를 생성한 상태라고 가정한다.

이번 작업은 게임 기능을 구현하는 단계가 아니다.  
앞으로 Codex가 이 프로젝트를 수정할 때 참고할 추가 기준만 정리하는 단계다.

## 작업 요청

현재 프로젝트 루트의 `AGENTS.md`를 수정해줘.

이미 생성된 기본 지침은 그대로 유지하고, 문서 맨 아래에 `프로젝트 전용 추가 지침` 섹션만 추가해줘.

## 중요

- 지금은 `AGENTS.md` 파일만 수정해줘.
- 요청한 부분 이외의 작업은 하지 마.

## 추가할 내용

아래 내용을 `AGENTS.md` 맨 아래에 추가해줘.

```md
## 프로젝트 전용 추가 지침

### 프로젝트 방향

- 이 프로젝트는 Unity 6.4로 만드는 간단한 슈팅 게임이다.
- 화면으로는 2D 슈팅 게임처럼 보이지만, Unity의 3D 공간을 기준으로 만든다.
- 처음부터 복잡한 구조를 만들지 않고, 작은 기능을 하나씩 추가하면서 완성한다.
- 구체적인 구현 방식은 각 단계에서 사용자가 요청하는 프롬프트를 우선한다.

### 작업 방식

- 한 번에 많은 기능을 만들지 않는다.
- 사용자가 요청한 기능만 구현한다.
- 다음 단계에서 사용할 것 같다는 이유만으로 미리 파일, 폴더, 오브젝트를 만들지 않는다.
- 필요한 파일과 폴더는 해당 기능을 구현할 때 생성한다.
- 기존에 만들어진 내용은 최대한 유지하면서 필요한 부분만 수정한다.
- 요청 범위를 벗어난 정리, 리팩터링, 구조 변경은 하지 않는다.

### 코드 작성 방향

- 코드는 처음 배우는 사람도 따라갈 수 있을 정도로 단순하게 작성한다.
- 복잡한 설계보다 눈으로 동작을 확인하기 쉬운 구현을 우선한다.
- 변수명과 함수명은 역할을 알 수 있게 작성한다.
- 같은 동작을 여러 번 설명해야 하는 경우에는 짧은 한글 주석을 사용한다.
- 고급 기능이나 복잡한 구조는 사용자가 요청하기 전에는 사용하지 않는다.

### Unity 작업 안내

- 코드만으로 끝나지 않는 작업은 Unity Editor에서 해야 할 일을 따로 알려준다.
- 새 스크립트를 만들었다면 어느 오브젝트에 붙여야 하는지 알려준다.
- Inspector에서 설정해야 하는 값이 있다면 어떤 값을 넣어야 하는지 알려준다.
- 직접 확인이 필요한 내용은 Play 모드에서 무엇을 보면 되는지 알려준다.

### 보고 방식

작업이 끝나면 아래 내용을 짧게 보고한다.

- 무엇을 바꿨는지
- 어떤 파일을 수정했는지
- 새로 만든 파일이나 폴더가 있는지
- Unity Editor에서 직접 해야 할 일이 있는지
- 확인하지 못한 내용이 있는지
```

## 완료 후 보고 형식

작업이 끝나면 아래 형식으로 짧게 보고해줘.

```text
작업 완료

수정한 파일:
- AGENTS.md

추가한 내용:
- 프로젝트 전용 추가 지침

새로 만든 파일 또는 폴더:
- 없음

확인할 내용:
- AGENTS.md 맨 아래에 프로젝트 전용 추가 지침이 추가되었는지 확인
```
