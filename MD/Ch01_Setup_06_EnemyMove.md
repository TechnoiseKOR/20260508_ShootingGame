# Ch01_Setup_06_EnemyMove

## 목표

Unity 슈팅 게임에서 사용할 적 오브젝트를 만들고, 적이 아래쪽으로 이동하게 한다.

이번 단계에서는 적을 자동으로 생성하지 않는다.  
씬에 배치된 적이 Play 모드에서 아래로 움직이는지만 확인한다.

## 작업 요청

AGENTS.md 기준으로 작업해줘.

이번 작업에서는 아래 내용만 진행해줘.

1. `Assets/Scripts` 폴더가 없다면 생성한다.
2. `Assets/Scripts/Enemy.cs` 스크립트를 만든다.
3. 기본 씬에 `Enemy` 오브젝트를 만든다.
4. `Enemy` 오브젝트에 `Enemy` 스크립트를 붙인다.
5. Play 모드에서 적이 아래쪽으로 계속 이동하게 한다.

## 중요

- 이번 작업은 적 오브젝트와 적 이동만 만든다.
- 적 자동 생성 기능은 만들지 마.
- 총알과 적 충돌 기능은 만들지 마.
- 플레이어와 적 충돌 기능은 만들지 마.
- 점수나 UI는 만들지 마.
- 요청한 부분 이외의 작업은 하지 마.

## 구현 기준

### Enemy 오브젝트

기본 씬에 `Enemy`라는 이름의 오브젝트를 만든다.

- 처음에는 단순한 3D 오브젝트를 사용해도 된다.
- 화면 위쪽에서 내려오는 것을 확인하기 쉽게 배치한다.
- `Enemy` 스크립트를 연결한다.

### Enemy 스크립트

`Enemy` 스크립트는 아래 기능만 담당한다.

- 적이 이동할 방향을 정한다.
- 매 프레임 아래쪽으로 이동한다.
- 이동 속도는 Inspector에서 조절할 수 있게 한다.

초반 수업에서는 이해하기 쉬운 코드를 우선한다.

예상 코드 흐름:

```csharp
Vector3 dir = Vector3.down;
transform.position += dir * speed * Time.deltaTime;
```
