# Ch01_Setup_02_CameraSetup

## 목표

Unity 슈팅 게임 제작을 시작하기 전에 기본 제작 환경을 정리한다.

이번 단계에서는 게임 기능을 구현하지 않고,  
씬에서 게임 화면을 보기 좋게 만들기 위한 카메라 설정과 기본 입력 처리 설정을 확인한다.

## 작업 요청

AGENTS.md 기준으로 작업해줘.

이번 작업에서는 아래 내용만 진행해줘.

1. 기본 씬의 Main Camera 설정을 확인한다.
2. 화면을 2D 슈팅 게임처럼 보기 좋게 만들기 위해 카메라의 Orthographic Size를 조정한다.
3. 프로젝트 입력 처리 설정을 확인한다.
4. 필요한 경우 Unity 기본 Input과 Input System이 함께 동작할 수 있도록 설정한다.
5. 임시 패치 파일이나 Visual Studio 설정 파일이 Git에 포함되지 않도록 `.gitignore`를 확인한다.

## 중요

- 이번 작업은 제작 환경 설정 단계다.
- 플레이어, 총알, 적 같은 게임 기능은 만들지 마.
- 새 스크립트를 만들지 마.
- 새 프리팹을 만들지 마.
- 요청한 부분 이외의 작업은 하지 마.

## 세부 기준

### 카메라 설정

기본 씬의 Main Camera는 2D처럼 보이는 슈팅 게임 화면을 보여주기 위한 기준 카메라로 사용한다.

- Projection은 Orthographic 상태를 유지한다.
- Orthographic Size는 게임 화면이 너무 좁거나 답답하지 않게 조정한다.
- 카메라 설정을 바꿨다면 어떤 값이 바뀌었는지 보고한다.

### 입력 처리 설정

이 프로젝트는 수업 진행 중 단순한 입력 처리를 사용할 수 있다.

Unity 프로젝트 설정에서 입력 처리 방식이 필요한 방향으로 되어 있는지 확인한다.

입력 처리 설정을 바꿨다면 어떤 값이 바뀌었는지 보고한다.

### Git 제외 설정

작업 중 생길 수 있는 임시 파일이 Git에 들어가지 않도록 `.gitignore`를 확인한다.

필요한 경우 아래와 같은 로컬 설정 파일은 제외한다.

- patch.diff
- .vsconfig
