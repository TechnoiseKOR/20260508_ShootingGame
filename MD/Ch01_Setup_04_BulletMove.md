# Ch01_Setup_04_BulletMove

## 목표

Unity 슈팅 게임에서 사용할 총알 오브젝트를 만들고, 총알이 위쪽으로 이동하게 한다.

이번 단계에서는 총알을 직접 발사하지 않는다.  
씬에 배치된 총알이 Play 모드에서 위로 움직이는지만 확인한다.

## 작업 요청

AGENTS.md 기준으로 작업해줘.

이번 작업에서는 아래 내용만 진행해줘.

1. `Assets/Scripts` 폴더가 없다면 생성한다.
2. `Assets/Scripts/Bullet.cs` 스크립트를 만든다.
3. 기본 씬에 `Bullet` 오브젝트를 만든다.
4. `Bullet` 오브젝트에 `Bullet` 스크립트를 붙인다.
5. Play 모드에서 총알이 위쪽으로 계속 이동하게 한다.

## 중요

- 이번 작업은 총알 오브젝트와 총알 이동만 만든다.
- 플레이어가 총알을 발사하는 기능은 만들지 마.
- 적 기능은 만들지 마.
- 충돌 처리 기능은 만들지 마.
- 점수나 UI는 만들지 마.
- 요청한 부분 이외의 작업은 하지 마.

## 구현 기준

### Bullet 오브젝트

기본 씬에 `Bullet`이라는 이름의 오브젝트를 만든다.

- 처음에는 단순한 3D 오브젝트를 사용해도 된다.
- 플레이어보다 위쪽에 배치해서 이동을 확인하기 쉽게 한다.
- 총알처럼 보이도록 크기를 작게 조정해도 된다.
- `Bullet` 스크립트를 연결한다.

### Bullet 스크립트

`Bullet` 스크립트는 아래 기능만 담당한다.

- 총알이 이동할 방향을 정한다.
- 매 프레임 위쪽으로 이동한다.
- 이동 속도는 Inspector에서 조절할 수 있게 한다.

초반 수업에서는 이해하기 쉬운 코드를 우선한다.

예상 코드 흐름:

```csharp
Vector3 dir = Vector3.up;
transform.position += dir * speed * Time.deltaTime;
```
