# Ch01_Setup_04_BulletMove_REVIEW

## 리뷰 대상

이번 리뷰 대상은 총알 생성 및 이동 구현 패치다.

패치 요약:

- 기본 씬에 `Bullet` 오브젝트 추가
- `Assets/Scripts/Bullet.cs` 추가
- `Bullet` 오브젝트에 `Bullet` 스크립트 연결
- 총알이 위쪽으로 이동하도록 구현

## 전체 평가

이번 작업은 플레이어 이동 이후 다음 단계로 적절하다.

아직 플레이어가 총알을 발사하는 단계는 아니지만,
총알이 어떤 오브젝트이고 어떻게 움직이는지 먼저 확인할 수 있다.

초급자에게는 “총알 발사”를 한 번에 구현하는 것보다,
먼저 “총알 자체가 움직인다”를 확인하는 방식이 이해하기 쉽다.

## 좋은 점

### 1. 기능 범위가 작다

이번 단계에서는 총알 이동만 구현했다.

다음 기능을 미리 만들지 않고,
총알 오브젝트와 총알 이동 스크립트에 집중한 점이 좋다.

### 2. 코드가 단순하다

`Vector3.up` 방향으로 이동하고,
`Time.deltaTime`을 곱해서 이동량을 계산하는 구조라서 이해하기 쉽다.

학생들이 이전 플레이어 이동 코드와 비교하면서 볼 수 있다.

플레이어 이동:

```csharp
Vector3 dir = new Vector3(h, v, 0.0f);
```

총알 이동:

```csharp
Vector3 dir = Vector3.up;
```

이렇게 비교하면 입력으로 움직이는 오브젝트와 자동으로 움직이는 오브젝트의 차이를 설명하기 좋다.

### 3. 오브젝트와 스크립트 연결 흐름이 반복된다

이전 단계에서 `Player`에 `PlayerMove`를 붙였다면,
이번에는 `Bullet`에 `Bullet` 스크립트를 붙인다.

반복되는 구조라서 Unity의 기본 작업 흐름을 익히기 좋다.

### 4. Inspector에서 속도를 확인할 수 있다

`speed` 값이 Inspector에 보일 수 있는 구조라서,
학생들이 값을 바꿔보며 총알 속도 변화를 바로 확인할 수 있다.

## 확인이 필요한 점

### 1. Play 모드에서 총알 이동 확인

Unity에서 Play 모드로 실행한 뒤 아래 내용을 확인한다.

- Bullet이 위쪽으로 이동하는지
- 속도가 너무 빠르거나 느리지 않은지
- 카메라 화면에서 이동이 잘 보이는지

### 2. 총알 위치와 크기 확인

현재 Bullet은 `{x: 0, y: 1.5, z: 0}` 위치에 있고,
크기는 `{x: 0.25, y: 0.6, z: 1}`로 설정되어 있다.

확인할 내용:

- Player와 구분되어 보이는지
- 너무 크거나 작지 않은지
- 화면에서 움직임이 확인되는지

### 3. 화면 밖으로 나가는 총알

현재 총알은 화면 밖으로 나가도 제거되지 않는다.

지금 단계에서는 문제가 아니지만,
나중에 총알을 계속 생성하게 되면 반드시 정리해야 한다.

## 개선하면 좋은 점

### 1. 빈 Start 메서드 정리

현재 `Start()`는 비어 있다.

수업 초반에는 그대로 둬도 되지만,
나중에 사용하지 않는 메서드는 삭제하는 것이 좋다.

### 2. public 필드 정리

현재 `speed`는 public 필드다.

초급 단계에서는 괜찮지만,
나중에 코드 스타일을 정리할 때는 `[SerializeField] private`로 바꾸는 것이 좋다.

### 3. 총알 삭제 처리

나중에 총알 발사 기능을 만들면,
화면 밖으로 나간 총알을 삭제해야 한다.

가능한 다음 단계:

- 일정 시간이 지나면 삭제
- 화면 밖 위치에 도달하면 삭제
- DestroyZone에 닿으면 삭제

## 다음 단계 제안

다음 단계는 플레이어가 총알을 발사하게 만드는 것이 자연스럽다.

추천 다음 작업:

```text
Ch01_Setup_05_PlayerFire
```

다음 단계에서 다룰 수 있는 내용:

- 플레이어 위치에서 총알 생성
- 스페이스바 입력으로 총알 발사
- 총알 오브젝트를 재사용하기 위한 준비
- 생성 위치 확인

다만 총알 발사 전에 총알을 프리팹으로 만드는 단계를 따로 둘 수도 있다.

선택 가능한 흐름:

```text
Ch01_Setup_05_BulletPrefab

```

수업 시간이 짧다면 `PlayerFire` 단계에서 프리팹 생성과 발사를 함께 다뤄도 된다.

## 최종 결론

이번 패치는 총알 이동 기능을 이해하기 좋은 단계다.

플레이어 이동 이후,
자동으로 움직이는 오브젝트를 추가했다는 점에서 수업 흐름이 자연스럽다.

다음 단계에서는 플레이어가 버튼을 눌렀을 때 총알을 생성하는 기능으로 이어가면 좋다.
